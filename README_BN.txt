বাংলা অফলাইন স্কুল ম্যানেজমেন্ট — প্রাথমিক PWA

এই সংস্করণে আছে:
- বাংলা শিক্ষার্থী ভর্তি ফর্ম
- তালিকা দেখা ও সার্চ
- তথ্য সম্পাদনা/মুছে ফেলা
- IndexedDB লোকাল ডেটাবেজ
- JSON ব্যাকআপ ও রিস্টোর
- PWA Service Worker ক্যাশিংয়ের প্রাথমিক ব্যবস্থা

গুরুত্বপূর্ণ:
1. Service Worker ও নির্ভরযোগ্য অফলাইন ইনস্টলেশনের জন্য HTTPS হোস্টিং অথবা localhost ব্যবহার করুন।
2. ZIP ফাইল সরাসরি ফোনের Downloads থেকে খুললে সব অফলাইন সুবিধা কাজ নাও করতে পারে।
3. শুরুতে GitHub Pages-এর মতো HTTPS static hosting-এ ফাইলগুলো প্রকাশ করুন, তারপর Chrome-এ খুলে Install/Add to Home Screen দিন।
4. একেকটি ডিভাইসে আলাদা IndexedDB থাকে। ডেটা স্বয়ংক্রিয়ভাবে কম্পিউটার ও ফোনের মধ্যে সিঙ্ক হয় না।
5. ব্রাউজারের ডেটা মুছে ফেললে তথ্য হারাতে পারে। নিয়মিত JSON ব্যাকআপ নিন এবং অন্য জায়গায় রাখুন।
6. এটি শেখা ও প্রাথমিক পরীক্ষার নমুনা; স্কুলের বাস্তব ব্যবহারের আগে নিরাপত্তা, ব্যাকআপ পুনরুদ্ধার, রিপোর্ট, পরীক্ষা, ফি এবং ডেটা যাচাই আরও পরীক্ষা করুন।
7. এই নমুনায় লগইন/এনক্রিপশন নেই। সংবেদনশীল বাস্তব শিক্ষার্থীর তথ্য এতে সংরক্ষণ করবেন না।

ফাইল:
index.html — UI
app.js — IndexedDB ও কার্যক্রম
manifest.json — PWA metadata\nicon.svg — অ্যাপ আইকন
sw.js — offline cache
